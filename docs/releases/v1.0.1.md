# OA阅答 v1.0.1

- Windows x64 轻量版包含私有 Python 运行环境及 office_oxide 0.1.15，不包含 LibreOffice。
- DOC 转换顺序为本机 Word → office_oxide → 可用 LibreOffice，使用转换后的 DOCX 作为单一上传来源。
- 页面、健康接口和三个 Windows 原生程序的版本统一为 1.0.1 / 1.0.1.0。
- 构建前校验 wheel SHA-256，发布时移除本机构建路径和字节码缓存。
- README 提供下载安装、登录、材料处理、争点分析、保存归档、数据目录及常见问题说明。
- 对 100–200 KB/s 上行网络给出传输时间估算；服务端解析和生成回答还需额外等待。

## 验证

- 在公开源码暂存目录运行 39 项 Python 测试：全部通过，无跳过。
- 真实二进制 DOC 合成文件回归：禁用 Word/LibreOffice 选择后，中文、表格、图片及图片引用保留。
- 发布 ZIP 的 2660 个条目 CRC 通过，安装器内嵌载荷与 ZIP 字节一致。
- 从含中文和空格的目录解压启动，健康接口返回 ready、bridgeVersion 1.0.1，页面及静态资源正常。
- 公开源码和 ZIP 检查未发现作者本机路径、账号缓存或案件目录。测试样本为合成材料。

这些检查不代表所有复杂 DOC、真实 NotebookLM 上传、OCR 联网初始化及安装器覆盖安装均已完整验收。

下载见 [v1.0.1 发布页](https://github.com/talenlin/oa-response-drafter/releases/tag/v1.0.1)。
